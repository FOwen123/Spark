# Agent logos

These marks identify the agents in Spark's "Connect your agent" dialog. The trademarks belong to
their owners; Spark uses them only to name the agent each setup applies to.

- `claude.svg`, `cursor.svg`, `opencode.svg`: [Simple Icons](https://simpleicons.org) 16.36.0,
  CC0 1.0 (https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md).
- `githubcopilot.svg`: the Copilot icon from GitHub's Primer Octicons, via Simple Icons; MIT license
  (GitHub Inc.) below.
- `openai.svg` (shown for Codex) and `antigravity.svg`: [Lobe Icons](https://github.com/lobehub/lobe-icons)
  1.101.0; MIT license (LobeHub) below.
- `vscode.svg`: [Devicon](https://github.com/devicons/devicon) 2.18.0 (`vscode-plain`); MIT license
  (konpa) below.
